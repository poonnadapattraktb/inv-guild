# INV Guild

เว็บแบบทดสอบอาชีพสำหรับสมาชิก INV Guild

## สถาปัตยกรรม

- Frontend เป็น static site (HTML/JS) deploy บน GitHub Pages
- ไม่มี backend server แยก หน้าเว็บเรียกใช้งานฐานข้อมูลผ่าน REST API โดยตรงจาก client

## Mode การใช้งานเว็บ

- **Guest mode**: เข้าที่ URL root (`/`) โดยไม่มี query parameter ผลแบบทดสอบจะไม่ถูกบันทึก เข้าได้ทุกคน
- **Member mode**: เข้าที่ URL พร้อม `?id=<NANO_ID>` เฉพาะสมาชิก (อักขระ URL-safe 8–21 ตัว เช่น `Uk8a1FT9`)
  - สมาชิกที่ยังไม่มีอาชีพ จะทำแบบทดสอบเลือกอาชีพได้หนึ่งครั้ง
  - สมาชิกที่มีอาชีพแล้ว จะเห็นหน้าโปรไฟล์ของตนเองแทน และไม่สามารถทำแบบทดสอบซ้ำได้

ทุก URL เริ่มต้นที่หน้า Home และต้องเปิดผ่าน HTTP server (เช่น `http://localhost:8000/`) ห้ามเปิดไฟล์ผ่าน `file://` เพราะ browser จะโหลดไฟล์ JSON ไม่ได้
